DONE
1. Added the thesis dataset (thiol-yne PEG hydrogels, Acıbadem BAP 2019/04) as a second project.
   - configs/thiol_yne_ha_hydrogel.yaml   samples, composition, methods, assumptions
   - knowledge/ftir_bands_thiol_yne.yaml  band table: S-H, alkyne, ester C=O, HA, PEG, residual DMF
   - Project data now lives in its own folder: data/thiol_yne/raw/, outputs in reports/thiol_yne/

2. New file readers
   - io/spa.py        Thermo Nicolet OMNIC .SPA (binary FTIR)
   - io/rheology.py   Malvern Kinexus CSV (semicolon, decimal comma) and generic G'/G'' tables
   - io/hydrogel.py   swelling workbook (one sheet per sample) and gel-conversion sheet
   - io/tga.py        fixed: now reads UTF-8 / Turkish (cp1254) headers. The mock benchmark found this bug.

3. New analyses
   - analysis/rheology.py  removes bad points automatically, recording a reason for each:
                           phase outside 0-90 deg (instrument inertia), harmonic distortion > 5 %,
                           strain not yet at the set value.
                           Reports G', G'', tan delta at 1 Hz, power-law exponent, crossover, gap.
   - analysis/hydrogel.py  swelling equilibrium, first-order rate constant, t90, data warnings;
                           gel fraction with a cross-check against values printed in a report.

4. Multi-project support
   - Each config has paths: data / reports / ftir_bands, plus per-sample "aliases" (regex) to match
     messy file names ("ali yuzde 10 smooth", "Reo_H_10PLA", sheet "10%", gel row "0.1").
   - Byte-identical files are detected and loaded once (reported as duplicates).
   - FTIR ratio windows and figure marker lines now come from the config, not the code.

5. Mock data generator + benchmark (src/biomatchar/mock.py, benchmark.py)
   - Writes a complete fake 4-sample study in REAL instrument formats: PerkinElmer .asc, OMNIC .spa,
     PANalytical .xrdml, HighScore .txt, machine SpreadsheetML .xls, TGA csv, Kinexus csv, swelling and gel xlsx.
   - Known ground truth for every number (ground_truth.json).
   - Two scenarios:
       clean : tidy data
       messy : noise, sloping baselines, duplicate exports, broken XML prolog, decimal commas,
               Turkish headers, rheometer inertia artefacts, 50 % harmonic distortion, empty swelling sheet
   - Benchmark compares pipeline output with the truth: 44 checks (clean), 51 checks (messy).
     Result: all checks pass on 2 clean and 3 messy seeds.
   - Commands:  biomatchar mock --scenario messy --seed 3
                biomatchar benchmark --scenario messy --seed 3

6. Agent
   - New tools: select_project, rheology_summary, swelling_summary, gel_fraction.
   - The agent now sees the config's assumption notes (for example "series interpretation: confirm").

7. Tests: 9 passing (readers, analyses, 3 benchmark runs, all agent tools on mock data).

KEY FINDINGS (thesis data, details in docs/findings_thiol_yne.md)
   - The files H_0/5/10/20PLA look like the PLA series, not the HA series: the 0 % file has no
     ester C=O at ~1757 cm-1 and the others do. The config now uses this reading. CONFIRM.
   - "ali ... smooth.SPA" and "ali ... raw.csv" are exact copies of the H_ files.
   - Rheology: tan delta 0.55 (blank), 0.11 (10 % PLA), 0.31 (20 % PLA), so PLA makes the gel more elastic.
     But the gap differs 0.70 / 0.23 / 0.41 mm, so the G' values are not yet comparable.
   - Swelling: no dry mass recorded, and only a 2-3.5 % gain, so the first weighing was already swollen.
   - Raw gel conversion (87.1/85.7/76.5/84.9 %) does not match report Table 4 (82.5/65.3/85.2/78.4 %),
     consistent with them being different series.
   - Strong ~1668 cm-1 band in the blank = probably residual DMF.

   - The 818 cm-1 band is in the control too, so it is not Zn-O (Zn-O is below the 650 cm-1 scan limit).

   - XRD: a sharp 26.0 deg peak appears in every film including the control; no ZnO peaks; all fillers amorphous.
   - Tensile: Zn films are not stronger than the control within the scatter.

========================================================================
ROADMAP (code improvements, in priority order)
========================================================================
 1. Swelling: fit sigmoidal / Peppas (M_t/M_inf = k t^n) models. The thesis curve has a lag phase that
    first-order kinetics does not describe.
 2. FTIR: degree of conversion from S-H and alkyne bands against a monomer reference spectrum;
    difference spectra (sample - control); peak fitting for overlapping bands.
 3. Rheology: amplitude sweep reader (linear viscoelastic limit), time sweep (gel point,
    G'/G'' crossover during UV curing), mesh size estimate from G' (rubber elasticity).
 4. SEM: pore size and porosity from images (thresholding + particle analysis), EDX spectrum reader.
 5. Statistics: ANOVA / Tukey between samples, report p-values, so text says "significant" only when it is.
 6. Literature: a reference library (BibTeX with DOIs you have verified) the agent can cite from.
    It will never invent a citation.
 7. Report builder: export the agent's results section to a Word / Google Doc with figures and tables.
 8. More formats: Bruker OPUS FTIR, TA Instruments TGA/DSC (.txt), Anton Paar rheometer, DSC analysis (Tg, Tm, crystallinity).
 9. Mock data: add DSC, SEM images and amplitude sweeps; add a "mislabelled sample" scenario the agent must detect.
10. CI: GitHub Actions running pytest + benchmark on every push.
